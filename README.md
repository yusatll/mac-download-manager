# MacDM — Mac Download Manager

A fast, native download manager for macOS — inspired by the classic Windows download managers, rebuilt with a Swift 6 / SwiftUI core: multi-connection downloads, pause & resume that survives restarts, a quality picker for video sites (YouTube and ~1800 more), and a browser extension that hands downloads over to MacDM.

**English** · [Türkçe için tıklayın](README.tr.md)

## Features

- **Multi-connection downloads** — files are split into segments and fetched over parallel connections with dynamic splitting, so supported servers deliver top speed (connection count configurable, 1–32).
- **Pause & resume, really** — segment state is saved to disk; quit the app, reboot, resume later. `ETag`/`Last-Modified` are honoured so a changed file is detected instead of corrupted.
- **Video downloads with a quality picker** — paste a YouTube (or Vimeo, X/Twitter, TikTok, Instagram, SoundCloud, Bilibili, …) link and choose `1080p · MP4 · ~450 MB`, `720p`, or *audio only*. Estimates match what actually lands on disk. QuickTime-friendly H.264/AAC is preferred by default.
- **Whole playlists** — paste a playlist link and every video lands in its own folder, numbered `001 - Title.mp4`, with the quality you picked.
- **Browser integration** — an extension for Chrome, Brave, Edge, Vivaldi and Safari: downloads that start in the browser are transferred to MacDM, links get a "Download with MacDM" right-click entry, and videos get a "⬇ Download this video" button right on the player.
- **IDM-style workflow** — categories (Compressed, Documents, Music, Programs, Video) with their own folders, queue with a concurrency limit, per-download and global speed limits, the segmented progress window, completion dialogs, menu-bar speed indicator, dock progress and notifications.
- **Clipboard watching** — copy a file or video link anywhere; MacDM offers to download it.
- **English + Turkish** interface, following your system language.

## Requirements

- macOS 14 (Sonoma) or newer, Apple Silicon or Intel
- For video downloads, three open-source tools on your PATH (one line with [Homebrew](https://brew.sh)):

```sh
brew install yt-dlp ffmpeg deno
```

> Keep yt-dlp fresh (`brew upgrade yt-dlp`) — sites change constantly and old versions lose formats.

## Install

### 1. The app

1. Download `MacDM.dmg` from [Releases](../../releases) and open it.
2. Drag **MacDM** to **Applications**.
3. First launch: the build is not yet notarized, so Gatekeeper will ask. Right-click **MacDM → Open → Open** (or run `xattr -cr /Applications/MacDM.app` once). Signed + notarized builds are on the roadmap.
4. On first launch MacDM shows a short setup window and puts itself in the menu bar.

### 2. The browser extension (Chrome / Brave / Edge / Vivaldi)

The extension is bundled with the repository and registered automatically when MacDM runs.

1. In your browser, open `chrome://extensions` (Brave: `brave://extensions`).
2. Enable **Developer mode** (top right).
3. Click **Load unpacked** and select the `Extension/dist/macdm-chrome` folder from the repository (or unpack `macdm-chrome.zip` from the release assets and select that folder).
4. Reload a tab — file downloads are now offered to MacDM, videos get the "⬇ Download this video" button, and links get a right-click menu.

A Chrome Web Store listing is planned; until then the unpacked install above is the way.

### 3. Safari

1. Open **Safari → Settings → Extensions** and enable **MacDM**.
2. Allow it to read/change pages when prompted.

Safari cannot intercept every download (no `chrome.downloads` equivalent there) — link clicks and the video button work; for everything else use the right-click menu.

## Using MacDM

- **Add URL** (⌘N), paste, or just copy a link — the file dialog shows size, category and folder before anything starts.
- **Video links** open the quality picker instead of downloading HTML. Playlist links show the entry count and download everything.
- **Pause/Resume** from the list, the progress window or the menu bar; state survives app restarts.
- **Speed limit** per download or globally (Settings → Connection).
- **Exceptions**: `*.apple.com`-style patterns and a minimum size keep sites/file types you don't want in the browser.

## Build from source

```sh
make bootstrap   # installs xcodegen if missing, creates Local.xcconfig
make app         # Debug build → build/Build/Products/Debug/MacDM.app
make dmg         # Release build → dist/MacDM.dmg
make test        # Swift (HDMCore + HDMIPC) and Node extension tests
```

Xcode 16+, Swift 6. The Xcode project is generated by XcodeGen (`make project`). Internal module names (`HDMCore`, `HDMIPC`) are from the project's first name and stay for path stability.

## How it works

```
Browser extension ── native messaging ──> macdm-bridge ─┐
Safari extension  ── sendNativeMessage ──> appex ───────┤
                                                        ▼
                              Unix-domain socket (HDMIPC, framed JSON)
                                                        ▼
   MacDM.app — DownloadManager · HTTPEngine (segmented HTTP) · MediaEngine (yt-dlp) · IPCServer
```

- `HTTPEngine` probes with `Range`, splits dynamically, retries with backoff, and re-validates on resume.
- `MediaEngine` drives `yt-dlp` (quality query + download), folds per-format progress into one monotonic bar, and merges to MP4 with ffmpeg.
- The full design lives in [`docs/superpowers/specs/2026-09-25-hiz-download-manager-design.md`](docs/superpowers/specs/2026-09-25-hiz-download-manager-design.md).
